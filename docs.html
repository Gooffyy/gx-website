1. SYSTEM PREREQUISITES

Before launching the GX Loader, ensure your Windows installation contains the necessary runtime libraries:

  • Operating System: Windows 10 (20H2 - 22H2) or Windows 11 (22H2 - 24H2) x64.
  • FiveM Build: Clean FiveM installation (Builds 3095, 3258, and Canary supported).
  • Visual C++ Redistributable: Microsoft Visual C++ 2015–2022 x64 must be installed.
  • DirectX: DirectX End-User Runtimes (June 2010).

2. WINDOWS DEFENDER EXCLUSION

Because GX MENU virtualizes and maps a Ring-0 kernel driver via undocumented CPU opcodes, Windows Defender or third-party AVs will falsely flag it as suspicious. Create a folder exclusion before downloading.

QUICK POWERSHELL EXCLUSION COMMAND
Open PowerShell as Administrator, paste this one-line command, and press Enter to instantly whitelist your folder:
Add-MpPreference -ExclusionPath "$env:USERPROFILE\Downloads\GX-Menu"

Extract the downloaded loader zip file into Downloads\GX-Menu. Never run the loader directly from inside an unextracted zip archive.

3. INJECTION SEQUENCE

  1. Launch GX_Loader.exe as Administrator.
  2. Input your 256-bit License Key (copied from your Client Portal) and press Enter.
  3. Wait for the console prompt: [+] Kernel Driver Initialized. Awaiting FiveM Process...
  4. Launch FiveM and connect to your chosen roleplay server.
  5. Once spawned inside the game world, press INSERT to toggle the menu overlay.

6. TROUBLESHOOTING & ERROR CODES

ERROR: 0x80070005 • ACCESS DENIED

Cause: Loader was launched without elevated administrative privileges or Windows Defender blocked driver write access.
Solution: Right click GX_Loader.exe → Properties → Compatibility → Check "Run this program as administrator". Ensure the folder is excluded in Defender.

ERROR: 0x00000002 • HWID MISMATCH

Cause: Your system motherboard or hardware components changed since your previous session.
Solution: Head to your Client Portal and click "RESET HARDWARE ID (HWID)".

MENU NOT SHOWING UP AFTER PRESSING INSERT

Solution: Check your FiveM Graphics Settings. Ensure Display Mode is set to "Windowed Borderless" or "Exclusive Fullscreen" with DirectX 11 enabled.
